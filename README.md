# 我的账号研究与拆解

一个用于账号诊断、对标研究、爆款拆解和内容布局的 AI Skill。以公开主页、实际读过的帖子、真实封面和可见数据为依据，输出能直接使用的中文分析。

重点面向小红书账号研究。也可以分析其他平台的账号，具体读取范围取决于运行环境已配置的工具。

## 可以做什么

| 任务 | 交付内容 |
|---|---|
| 账号诊断 | 定位、人设、受众、内容主线、关注理由和优先调整动作 |
| 找对标 | 同阶段账号、成熟标杆、真实主页、近期代表作及学习条件 |
| 拆爆款 | 选题、标题、真实封面、开头、内容结构、证明方式和评论需求 |
| 研究账号演化 | 比较置顶、近期与可获取的起步期内容，标注日期和代表作 |
| 做内容布局 | 区分引流、信任与转化承接，把样本拆解聚合成栏目与下一次实验 |

默认输出方便复制的中文文字版。HTML报告、Excel、图片或完整文案按任务要求选择。

## 安装到 Codex

将仓库放入个人技能目录：

```bash
git clone https://github.com/Yana262268/my-account-research.git ~/.codex/skills/my-account-research
```

其他支持 `SKILL.md` 的代理可将整个仓库放入其技能目录。

## 怎么调用

账号诊断：

```text
$my-account-research 拆解这个账号的定位、人设、内容栏目和转化承接，给出有证据的调整建议。
账号主页：粘贴链接
```

对标研究：

```text
$my-account-research 按AI出海营销方向找5个同阶段个人IP，给真实主页、近期代表作和具体学习理由。
```

爆款与内容布局：

```text
$my-account-research 拆解这些账号的置顶、近两个月和可获取的起步期帖子，区分引流款和转化款，再整理适合我的内容布局。
账号主页：粘贴链接
我的受众与目标：填写内容
```

近期帖子筛选：

```text
$my-account-research 找近三天适合留学生实习求职受众的高赞帖子，核对原始发布时间，拆解标题与内容结构。
```

## 调整成自己的研究习惯

编辑 [references/profile.md](references/profile.md)，修改研究方向、受众、对标体量、互动门槛和交付偏好。内置的求职实习与AI营销方向都是可调整的起点，本次明确要求优先。

已有账号链接或材料时直接使用。影响候选选择的关键信息缺失时，再补充最少的问题。

## 材料与工具

- 可以使用已配置的网页读取、浏览器、平台工具，也可以使用截图、粘贴正文或导出材料；分析中会说明实际覆盖范围。
- `my-web-collection` 可作为批量采集的协作入口；当前环境没有它时，仍可用已有工具或用户材料研究。
- `lingzao` 属于可选工具，需要单独配置其认证与所需额度；安装本仓库不会附带服务账户。
- 分析原图之前需要实际取得图像；判断正文结构之前需要实际读到正文。

结果保留来源和观察日期，区分可见事实与推断。缺少曝光、私信、成交等数据时，给出待验证的解释与下一步实验。
